# 04 · 配对插件：把插件连接到你的站点

插件需要知道「把笔记保存到哪个站点」。通过「一键短链接配对」完成，整个过程不需要手动复制 Token。

## 一、在你的站点后台生成配对链接

1. 用作者账号登录你的站点后台（`https://你的域名/admin`）。
2. 左侧菜单点击 **插件配对**。
3. 在「一键短链接配对（推荐）」区域，点击 **生成配对链接**。
4. 复制生成出来的完整短链接（形如 `https://你的域名/pair?token=pair_xxxx...`）。
   - 该链接 60 分钟内有效，且只能用一次。

---

## 二、在插件中完成配对

1. 点击浏览器工具栏的「极简笔记」图标。
2. 首次使用会看到「立即配置插件」，点击进入设置页。
   - 也可以直接右键插件图标 → **选项（Options）** 进入设置页。
3. 默认就在「一键短链接配对」标签页。
4. 把第一步复制的短链接粘贴到输入框。
5. 点击 **开始配对**。
6. 看到「配对成功」，并显示已连接的站点域名，即完成。

之后点击插件图标，就能直接开始速记，保存会写入你自己的站点数据库。

---

## 三、手动配置（兜底方案）

如果无法使用短链接配对（例如网络受限），可以手动配置：

1. 站点后台 → **插件配对** → 拉到「手动 Token 管理」。
2. 填一个 Token 名称（如「我的 Chrome」），点击 **创建 Token**。
3. 复制生成的 Token（形如 `mntok_xxxx...`），它只显示一次。
4. 打开插件设置页，切换到「手动配置」标签。
5. 填入你的站点域名（`https://你的域名`）和刚才的 Token。
6. 点击 **测试连接并保存**。

---

## 四、验证是否成功

配对成功后，在任意网页点击插件图标，随便写几个字，点「保存到我的站点」。然后回到站点后台 → **笔记**，就能看到刚保存的速记笔记。

---

## 常见问题

- **配对链接提示已过期/已使用**：配对链接是一次性的，且 60 分钟过期。请回到后台重新生成。
- **插件保存失败提示 401**：Token 失效或已吊销。重新执行上面的配对流程即可。
- **想切换连接的站点**：重新生成配对链接，按上面流程再配对一次，会覆盖旧配置。
