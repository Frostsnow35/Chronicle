# 需求边界（ALIGNMENT）

> 更新日期：2026-09-06

## 目标

为 Chronicle 落地中国大陆访问加速，第一阶段聚焦两项见效最快的优化：

1. 首屏性能：移除阻塞渲染的 Google Fonts 外链，改用系统字体栈。
2. 图片加速：上传时服务端压缩转 webp，渲染时注入懒加载。

## 约束（硬边界）

- 不改 Vercel + Supabase 架构，不引入自定义域名。
- 保持独立部署模式与单作者模式不变。
- 本次不动插件图片链路（base64 内嵌问题留到第二阶段）。

## 硬限制（客观网络事实）

`*.vercel.app` 与 `*.supabase.co` 属跨境访问，DNS 解析与连接层不稳定无法通过应用代码根治。本次仅优化代码可控部分，网络层抖动仍会存在。

## 范围外

- 插件图片改为上传 Storage（去 base64）
- 缩略图生成与响应式图片
- CDN/镜像加速
- 自定义域名方案
